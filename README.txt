NicholasFashion Word website

Files:
- index.html: page structure and content
- style.css: responsive visual design
- script.js: slideshow, 50-item demo catalogue, filters, search, product modal and WhatsApp enquiry

How to run:
1. Extract the ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Replace the sample image URLs, product names, descriptions and prices in script.js with your real catalogue.
4. Update the WhatsApp number in script.js if needed.

Note:
The catalogue currently contains 50 sample entries generated from 12 sample style records. Prices and products are placeholders. WhatsApp uses the international format generated from 08164406684 (Nigeria: 2348164406684).
